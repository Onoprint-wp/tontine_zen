## 1. PRÉSENTATION DU DESIGN SYSTEM

### 1.1. Origine et Choix

Ce design system est inspiré du template **Pockora** (Codester), que j'ai recommandé pour son excellence dans le domaine financier. Pockora propose :

- **36+ écrans premium** pour la gestion financière
- **Des widgets modulaires et réutilisables**
- **Une architecture MVVM** avec gestion d'état Cubit/BLoC
- **Une charte graphique moderne et professionnelle**
- **Des composants adaptés aux besoins d'épargne et de budget**

### 1.2. Adaptation pour TONTINE ZEN LIGHT

Ce design system est adapté de Pockora pour répondre aux besoins spécifiques de votre projet :

| Besoin TONTINE ZEN LIGHT | Adaptation de Pockora |
| :--- | :--- |
| **Gestion de tontine (groupes d'épargne)** | Les écrans "Budgets" et "Savings Goals" de Pockora sont réutilisés |
| **Score de réputation** | Les "Smart Insights" de Pockora sont adaptés pour afficher les scores |
| **Contrat OHADA** | Ajout d'un module "Documents" et "Signature" |
| **Médiation** | Ajout d'un module "Litiges" et "Messagerie" |
| **Contexte africain** | Adaptations culturelles (couleurs, icônes, langues locales) |

### 12.2. Widgets Personnalisés (Composants)

```dart
// lib/widgets/reputation_score.dart
import 'package:flutter/material.dart';

class ReputationScore extends StatelessWidget {
  final int score;

  const ReputationScore({Key? key, required this.score}) : super(key: key);

  Color _getScoreColor() {
    if (score >= 90) return Color(0xFF2F855A);
    if (score >= 70) return Color(0xFFD69E2E);
    if (score >= 40) return Color(0xFF3182CE);
    return Color(0xFFE53E3E);
  }

  String _getScoreLabel() {
    if (score >= 90) return 'Excellent';
    if (score >= 70) return 'Bon';
    if (score >= 40) return 'Moyen';
    return 'Faible';
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: EdgeInsets.symmetric(horizontal: 12, vertical: 6),
      decoration: BoxDecoration(
        color: _getScoreColor(),
        borderRadius: BorderRadius.circular(20),
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(
            Icons.star,
            color: Colors.white,
            size: 14,
          ),
          SizedBox(width: 6),
          Text(
            '$score • ${_getScoreLabel()}',
            style: TextStyle(
              color: Colors.white,
              fontSize: 12,
              fontWeight: FontWeight.w600,
            ),
          ),
        ],
      ),
    );
  }
}
```

### 14.3. Intégration avec Supabase

```dart
// lib/services/supabase_service.dart
import 'package:supabase_flutter/supabase_flutter.dart';

class SupabaseService {
  static final SupabaseService _instance = SupabaseService._internal();
  factory SupabaseService() => _instance;
  SupabaseService._internal();

  final supabase = Supabase.instance.client;

  Future<List<Map<String, dynamic>>> getTontines(String userId) async {
    final response = await supabase
        .from('tontines')
        .select()
        .eq('user_id', userId);
    return response;
  }

  Future<void> createTontine(Map<String, dynamic> data) async {
    await supabase
        .from('tontines')
        .insert(data);
  }
}
```

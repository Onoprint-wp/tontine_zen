# Localization Skill

## Directives
- **Fichiers de traduction** : Utiliser la structure standard de fichiers d'internationalisation de Flutter (fichiers JSON ou ARB dans `/lib/l10n/`).
- **Support local** : Les tutoriels vidéo ou vocaux pour l'inclusion des personnes moins alphabétisées doivent être indexés par code de langue locale (ex: `fr_CM`, `dou_CM`, `bam_CM`, `ful_CM`).
